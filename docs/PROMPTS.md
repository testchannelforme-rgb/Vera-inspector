# Prompt generation contract 0.3 (V0.3.1 implementation)

`POST /api/prompts/generate`, same-origin and the existing `X-Veyra-Client: inspector-v0.1` header. The header value is retained for compatibility with V0.2. Request bodies remain limited to 8 KiB and extra fields are forbidden. Website text/HTML/URLs cannot be supplied by the client.

```json
{
  "sessionId": "CURRENT_SESSION_TOKEN",
  "frameId": "CURRENT_FRAME_ID",
  "referenceId": "CURRENT_SELECTION_REFERENCE",
  "scope": "element",
  "target": "react",
  "detail": "detailed",
  "style": "faithful",
  "mode": "local"
}
```

Enums: scope `element|section|page`; target `html-css|html-css-js|react`; detail `concise|detailed|highly-detailed`; style `faithful|responsive|accessible`; mode `local|auto`. Page needs no selection/reference; the other scopes require the active retained element reference. All scopes require the current screenshot frame ID. A fresh snapshot is collected under the existing session operation lock and a separate five-second evidence deadline. The provider runs after that browser lock is released.

Success includes `schemaVersion: "0.3"`, `generationId`, `prompt`, `mode: "ai"|"fallback"`, nullable provider/model metadata, warnings and an evidence summary (root tag, scope/boundary, sample count, viewport, capture timestamp and truncation flag). Inspection JSON remains schema 0.1. Typical failures: 409 stale selection/frame, 404 closed session, 422 no visible/safe target, page-wrapper section selection or malformed body, 429 concurrent/rate-limited generation. Provider failures return a 200 fallback result with a safe warning; raw provider errors are discarded.

Collection bounds remain 55 output nodes, at most 1,500 queued/visited nodes, 16 levels, 120 ms best-effort total page budget and 48,000 serialized sanitized evidence bytes. Scored boundaries use at most 11 ancestors/64 children each, inside a 20 ms sub-budget. Discovery uses a selected-path-pinned breadth-first walk; CSS is read for a prioritized ancestor-closed sample. The five-second backend deadline/browser resource limits remain outer bounds. Detail modes prioritize up to 4/12/28 nodes while retaining every included sanitized CSS property. A selected ancestor path can exceed the nominal detail count and is disclosed; it cannot exceed the evidence byte budget. Original IDs/parents and captured DOM sibling indices are preserved; no orphan node is silently reparented.

Optional additive evidence fields: `boundaryDecision` (method/tag/distance/score/reasons/candidate rejections), `collection` (visited/candidate/returned counts, elapsed time, selected coverage), `sampling` (omission/invalid/context status), node `selected`, `siblingIndex`, `parentRelationship`, `viewportIntersection`, `accessibility`, `styleTruncatedProperties`, and `sanitizedProperties`. The legacy schema name `0.3-evidence`, response schema 0.3, request body/enums and inspection schema 0.1 remain compatible. Older evidence without these fields still renders.
The collector retains typed structure, direct visible text, selected computed CSS, image dimensions and interaction indicators. It excludes HTML, scripts, form values, editable descendant text, arbitrary attributes, full URLs, cookies and browser storage. `[data-veyra-private]` marks a private region whose copy/descendants are excluded (a selected root's styling can still be measured). Background asset URLs are replaced by a presence flag; URL-free computed gradients can be retained. Internal CSS whitespace is preserved; privacy/length modifications are flagged. Heuristic text redaction removes email addresses and common credential-like strings. Other personal information can remain in visible page copy: inspect public content only and use local mode unless sending reduced data to the configured provider is appropriate.

Section scope scores local semantic/painted/layout containers and rejects page landmarks, disproportionate tall wrappers and unrelated direct landmark groups. It retains the nearest safe parent/selection when no strong local candidate exists. A selected main/body/html/page-main role yields `422 prompt-section-too-broad` with guidance to choose a local child or page scope. The boundary is heuristic and carries its explanation. Page still samples the current body at its scroll position. Open shadow roots can be sampled; iframe documents/closed shadow roots are opaque. Visibility and viewport intersections are not complete clipping/occlusion analysis. DOM indicators do not prove activation behavior. Existing hover comparisons apply only to the exact selected element; their prior timing/baseline limitations remain disclosed.
The local renderer emits objective, hierarchy, layout, styling, interactions, responsiveness, implementation requirements and accuracy notes. Equal style strings are factored into shared groups plus node-specific values; merging them reconstructs each included sanitized map exactly, without claiming inheritance or original authored rules. Known numbers remain measured; absent breakpoints/states/assets are never supplied as facts. Recommendations are explicitly labelled. React/HTML preferences change instructions only, not executable code.

The AI adapter uses a separate system message, JSON-encoded untrusted evidence, a fixed administrator-configured endpoint and no tools. It cannot receive cookies, API credentials or browser service capabilities through the evidence path. It validates three interpretation strings, rejects truncated/oversized/unusable output and preserves the deterministic measurements as authoritative. This reduces prompt-injection impact; it does not prove arbitrary model prose safe or correct. The downstream coding tool must also treat quoted website copy and AI interpretation as untrusted. All output is a React-controlled textarea; no HTML execution, Markdown renderer, tools, network commands or generated code execution is enabled.

Limits per single-worker app: one generation at a time, 3 attempts/session/minute, 10 attempts/global/minute; 64 KiB provider request/response envelopes, 1–20 second total provider deadline, output token cap and 60,000-character final prompt. Calls have no automatic retry, redirects, environment proxy inheritance or private-address endpoint support. The reused public-DNS gate pins the actual numeric connection and TLS verifies the configured hostname. Missing/invalid configuration fails closed to local mode. Configuration must be trusted backend administration; this is not a public multi-user service or a spending firewall.
