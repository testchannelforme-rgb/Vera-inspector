## Run privately in the existing Codespace

After checking that uncommitted files are preserved, select this branch. Use the existing environment:

```bash
npm --prefix frontend ci
npm --prefix frontend run build
bash start.sh --isolated
```

Keep forwarded app port **Private**. This repository's existing Compose maps app port **8001** to container port 8000; inspect `compose.inspection.yml` and use the existing forwarded app port. The restricted local start `bash start.sh` serves port 8000 and permits only configured hosts. Do not disable the Chromium sandbox or change URL/network policy to make a failing probe pass.

No production deployment, account system, payments, subscription, cloud coding, image generator or paid integration is included. V0.3.3 does not activate an AI provider or change its key/configuration.

## Reproduce tests

Build before API/UI tests, since FastAPI mounts `frontend/dist` when the app is created:

```bash
npm --prefix frontend test
npm --prefix frontend run build
.venv/bin/python -m pytest -q -rs
.venv/bin/python -m pytest -q -rs backend/tests/test_v033_ui.py
PYTHONPATH=backend .venv/bin/python scripts/check_browser.py
```

Browser checks require an installed sandbox-capable Chromium host. Screenshots from the new browser acceptance tests are written to ignored `artifacts/generated/v033`. No mocked sample is described as a live website inspection. `--public` separately enables the existing real example.com navigation test. Local browser download failures and skipped tests must remain disclosed in the test report.
